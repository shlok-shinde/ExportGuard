CRITICAL DISCOVERY // THE GZIP -T BLIND SPOT

WHY `GZIP -T` IS NOT ENOUGH

If an export process crashes mid-stream (OOM, killed pipe, network disconnect), the standard Unix pipeline expdp ... | gzip > dump.gz receives an EOF. Gzip happily writes a valid CRC32 trailer for the truncated stream! Running gzip -t dump.gz returns code 0 (PASS), while 30,000 rows were silently lost forever.
